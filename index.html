How I run a project

Chapter 05

  1. Kickoff

    A prioritised question list for the client, so the decisions that block the plan get answered first.

  2. Requirements

    BRD for the business goals, FRD for testable behaviour, with acceptance criteria QA can tick off.

  3. Plan & handover

    A timeline sheet with owners and milestones, and a walkthrough with engineers before build starts.

  4. Build & UAT

    Daily tracking, early escalation of blockers, then demos and UAT with the client on real workflows.

  5. Launch & improve

    User guides in the users’ own language, then a steady feedback loop into the next release.
